Chat On Steroids 2.0.3 continues the native Windows/macOS/Linux packaging matrix introduced in
2.0.2. The app and standalone companion extension are versioned together, so **reload the browser
extension after updating the app**.

Choose the artifact for your operating system and CPU:

- `Chat-On-Steroids-Setup-x64.exe` — Windows x64 (Intel/AMD)
- `Chat-On-Steroids-Setup-arm64.exe` — Windows on Arm
- `Chat-On-Steroids-macOS-x64.dmg` — macOS Intel disk image
- `Chat-On-Steroids-macOS-x64.zip` — macOS Intel app archive
- `Chat-On-Steroids-macOS-arm64.dmg` — macOS Apple silicon disk image
- `Chat-On-Steroids-macOS-arm64.zip` — macOS Apple silicon app archive
- `Chat-On-Steroids-Linux-x64.AppImage` — Linux x64 portable AppImage
- `Chat-On-Steroids-Linux-x64.deb` — Linux x64 Debian/Ubuntu package
- `Chat-On-Steroids-Linux-arm64.AppImage` — Linux ARM64 portable AppImage
- `Chat-On-Steroids-Linux-arm64.deb` — Linux ARM64 Debian/Ubuntu package
- `Chat-On-Steroids-Extension.zip` — standalone Chrome companion extension
- `latest.yml` — Windows x64 update metadata
- `latest-arm64.yml` — Windows ARM64 update metadata
- `latest-linux.yml` — Linux x64 update metadata
- `latest-linux-arm64.yml` — Linux ARM64 update metadata
- `SHA256SUMS.txt` — SHA-256 checksums for every release artifact above

> **macOS caveat:** the 2.0.3 DMG and ZIP builds are currently **publisher-unsigned (no Apple
> Developer ID) and unnotarized**. Apple-silicon Mach-O executables may still contain platform-required

## 2.0.3

2.0.3 hardens long-running ChatGPT work on the 2.0.2 cross-platform runtime. Goal, Compact &
Resume, tunnels, caller identity, app updates and the unpacked companion extension now have
explicit recovery/compatibility state rather than depending on a healthy foreground tab or a
manual app restart.

### What changed

- Goal now defaults to GLM 5.3 Flash and retries transient provider/transport failures — up to
  three same-model attempts — without turning an error into a ChatGPT message. Failures retrying
  cannot fix (a non-transient HTTP status, or malformed/over-long model output) stop after one
  attempt instead of burning the budget. The opening message a saved Goal sends into a new chat
  follows the same policy. Durable draft/receipt state prevents duplicate sends after timeout,
  retry, app restart or MV3 worker restart; repeated failure offers manual Retry.
- Compact & Resume reacts to a usable composer immediately, preserves the same session/Goal across
  the replacement chat, and remains exactly-once or retryable through interruption, and now reports
  how long its browser half actually took in the completion log. A resume can no longer lose its
  session to its own replacement chat: observations arriving from a chat the app has not recorded
  are held as retryable while a move might still claim it, instead of creating a second session the
  move then refuses to overwrite. The settings gear survives SPA navigation; New Chat no longer
  shows a meaningless Compact pill.
- Windows NSIS and Linux AppImage/DEB builds use official GitHub update metadata. The top bar shows
  check/download/install state, never installs on ordinary quit, excludes prereleases/downgrades,
  and keeps app startup usable when the release service is offline. macOS updates remain manual.
- App/extension version and bridge protocol mismatches are explicit. The app refreshes/reveals its
  exact bundled unpacked extension and tells the user when Chrome must Reload it.
- **Uncaptured chat access** is a new, off-by-default fallback principal with its own workspace and
  terminal ownership. It cannot impersonate or steal state from a captured conversation, and
  turning it off takes effect at once — its terminals are killed, its remembered folder is dropped,
  and a command that was mid-start is refused rather than left running.
- Cloudflare helper crashes and startup timeouts now reconnect with bounded backoff and stale-child
  fencing. Session cursors and command/DOM hot paths were reduced to avoid opaque payload churn,
  unnecessary reruns and foreground-timer latency.

### Platform and safety boundaries

- The release matrix still builds six native jobs: Windows x64/ARM64, macOS Intel/Apple silicon
  and Linux x64/ARM64, with packaged-runtime smoke tests before upload.
- Windows alone exposes Desktop screenshot/input/clipboard tools. Core, the extension bridge,
  Goal, Compact & Resume and tunnels ship on all three OS families.
- Linux AppImage behavior remains explicit: the static launcher can add `--no-sandbox` when
  unprivileged user namespaces are unavailable. On Debian/Ubuntu hosts that restrict namespaces,
  prefer the DEB if you do not want that fallback.
- Release binaries are still publisher-unsigned; metadata SHA-512/SHA-256 checks provide integrity,
  not a publisher signature. Verify `SHA256SUMS.txt` before overriding an OS warning.

> Beta despite the version number. Behaviour may still change between releases.
